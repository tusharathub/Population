
# World Population Simulator

Welcome to the World Population Simulator — a fun, interactive website where you can play god with humanity (responsibly)

## What it does
Shows a real-time world population counter

Adjust birth rate, ☠death rate, and ✈ migration rate

Visual donut chart showing population by continent

Trigger fun global events like pandemics or baby booms

Pause, reset, or completely wipe out humanity (if that’s your thing)
